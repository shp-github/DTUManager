# Modbus 模板配置格式说明文档

**版本**: v1.1  
**更新日期**: 2026-06-28  
**适用范围**: Modbus RTU/TCP 通信配置

---

## 1. 概述

本文档描述了一种模板化 Modbus 配置格式，通过将指令抽象为模板，配合从站地址列表自动生成 Modbus 报文。该格式大幅减少配置文件的体积，解决嵌入式设备 JSON 解析时的内存不足（NoMemory）问题。

每条指令模板包含**读功能码**和可选的**写功能码**，支持读后写场景（如读取状态后下发控制指令）。

---

## 2. 快速开始

### 2.1 单模板（统一从站列表）

```json
{
  "modbus": {
    "enabled": true,
    "protocol": "rtu",
    "inputSource": "serial1",
    "outputSource": [0],
    "interval": 50,
    "addrs": [1, 2, 3],
    "template": [
      [
        "03",
        0,
        18,
        "",
        [
          ["", 0, 2, 0],
          ["", 2, 2, 0],
          ["", 4, 2, 0]
        ]
      ]
    ]
  }
}
```

### 2.2 多模板（不同从站使用不同指令）

```json
{
  "modbus": {
    "enabled": true,
    "protocol": "rtu",
    "inputSource": "serial1",
    "outputSource": [0],
    "interval": 50,
    "templates": [
      {
        "addrs": [1, 2, 3],
        "commands": [
          ["03", 0, 18, "", [["",0,2,0],["",2,2,0],["",4,2,0]]]
        ]
      },
      {
        "addrs": [6, 7, 8],
        "commands": [
          ["03", 100, 6, "06", [["",100,2,0],["",102,2,0],["",104,2,0]]]
        ]
      }
    ]
  }
}
```

## 3. 顶层参数说明

| 字段           | 类型    | 必填 | 说明                      | 示例                      |
| -------------- | ------- | ---- | ------------------------- | ------------------------- |
| `enabled`      | boolean | 是   | 是否启用 Modbus 功能      | `true`                    |
| `protocol`     | string  | 是   | 通信协议类型              | `"rtu"` 或 `"tcp"`        |
| `inputSource`  | string  | 是   | 数据输入源                | `"serial1"`, `"serial2"`  |
| `outputSource` | array   | 是   | 数据输出目标通道          | `[0]`                     |
| `interval`     | number  | 是   | 轮询间隔（毫秒）          | `50`                      |

### 3.1 单模板模式（`addrs` + `template`）

| 字段       | 类型  | 必填 | 说明                  | 示例                |
| ---------- | ----- | ---- | --------------------- | ------------------- |
| `addrs`    | array | 是   | 从站地址列表          | `[1, 2, 3, 4, 5]`   |
| `template` | array | 是   | 指令模板列表          | 见下文              |

### 3.2 多模板模式（`templates`）

| 字段         | 类型  | 必填 | 说明                          |
| ------------ | ----- | ---- | ----------------------------- |
| `templates`  | array | 是   | 模板组列表，每组含独立的从站地址和指令 |

`templates` 中每个元素的结构：

| 字段       | 类型  | 必填 | 说明           |
| ---------- | ----- | ---- | -------------- |
| `addrs`    | array | 是   | 从站地址列表   |
| `commands` | array | 是   | 指令模板列表   |

---

## 4. 模板格式说明

### 4.1 单条模板结构

```json
[
  "03",                    // 读功能码（十六进制字符串）
  0,                       // 起始寄存器地址
  18,                      // 寄存器数量
  "06",                    // 写功能码（十六进制字符串，空字符串表示只读）
  [                        // 参数映射列表
    ["", 0, 2, 0],         // [Key, 偏移, 长度, 字节序]
    ["", 2, 2, 0],
    ["", 4, 2, 0]
  ]
]
```

| 位置     | 类型   | 说明                                    | 示例                  |
| -------- | ------ | --------------------------------------- | --------------------- |
| `[0]`    | string | 读功能码（十六进制）                    | `"01"`, `"02"`, `"03"`, `"04"` |
| `[1]`    | number | 起始寄存器地址                          | `0`, `18`, `36`       |
| `[2]`    | number | 寄存器数量                              | `18`, `6`, `12`       |
| `[3]`    | string | 写功能码（十六进制），空字符串 `""` 表示只读不写 | `""`, `"05"`, `"06"`, `"10"` |
| `[4]`    | array  | 参数映射列表                            | 见下表                |

### 4.2 参数映射格式

```json
["", 寄存器偏移, 数据长度, 字节序]
```

| 位置     | 类型   | 说明                            | 示例        |
| -------- | ------ | ------------------------------- | ----------- |
| `[0]`    | string | Key 名称（留空自动生成）        | `""`        |
| `[1]`    | number | 寄存器偏移（相对于起始地址）    | `0`, `2`, `4` |
| `[2]`    | number | 数据长度（字节数）              | `1`, `2`, `4` |
| `[3]`    | number | 字节序类型                      | `0`, `1`, `2`, `3` |

---

## 5. 功能码说明

### 5.1 读功能码（`[0]`）

| 功能码 | 名称               | 说明                   | 寄存器范围 |
| ------ | ------------------ | ---------------------- | ---------- |
| `01`   | 读线圈             | Read Coils             | 0xxxx      |
| `02`   | 读离散输入         | Read Discrete Inputs   | 1xxxx      |
| `03`   | 读保持寄存器       | Read Holding Registers | 4xxxx      |
| `04`   | 读输入寄存器       | Read Input Registers   | 3xxxx      |

### 5.2 写功能码（`[3]`）

| 功能码 | 名称               | 说明                     | 适用场景           |
| ------ | ------------------ | ------------------------ | ------------------ |
| `""`   | 无（只读）         | 仅读取，不执行写操作     | 数据采集、监控     |
| `05`   | 写单线圈           | Write Single Coil        | 开关控制           |
| `06`   | 写单个寄存器       | Write Single Register    | 参数设置           |
| `10`   | 写多个寄存器       | Write Multiple Registers | 批量参数下发       |

> **读后写机制**：当写功能码不为空时，设备先执行读功能码获取数据，再根据写功能码下发写指令。这通常用于"读取当前状态 → 根据条件写入控制指令"的场景。

---

## 6. 报文自动生成规则

程序根据从站地址和模板自动生成 Modbus 报文：

```text
读报文 = 从站地址(2位) + 读功能码(2位) + 起始地址(4位) + 寄存器数量(4位)
写报文 = 从站地址(2位) + 写功能码(2位) + 起始地址(4位) + [数据]
```

> 写报文在写功能码不为空时生成，紧跟在读报文之后发送。

### 6.1 生成示例

| 从站地址 | 读功能码 | 起始地址 | 寄存器数量 | 生成读报文       |
| -------- | -------- | -------- | ---------- | ---------------- |
| 1        | "03"     | 0        | 18         | `010300000012`   |
| 1        | "03"     | 18       | 18         | `010300120012`   |
| 2        | "03"     | 0        | 18         | `020300000012`   |
| 10       | "03"     | 0        | 18         | `0A0300000012`   |

| 从站地址 | 写功能码 | 起始地址 | 数据     | 生成写报文       |
| -------- | -------- | -------- | -------- | ---------------- |
| 1        | "06"     | 100      | 0x0064   | `010600640064`   |
| 1        | "10"     | 0        | 多寄存器 | `01100000000N...` |

### 6.2 Key 自动生成规则

```text
实际寄存器地址 = 起始地址 + 偏移
Key = "从站地址:实际寄存器地址"
```

| 从站 | 起始地址 | 偏移 | 实际地址 | 生成 Key |
| ---- | -------- | ---- | -------- | -------- |
| 1    | 0        | 0    | 0        | `"1:0"`  |
| 1    | 0        | 2    | 2        | `"1:2"`  |
| 2    | 18       | 0    | 18       | `"2:18"` |

---

## 7. 字节序类型说明

| 值 | 名称   | 说明                       | 示例（0x1234） |
| -- | ------ | -------------------------- | -------------- |
| 0  | ABCD   | 大端模式（标准 Modbus）    | `12 34`        |
| 1  | CDAB   | 小端模式                   | `34 12`        |
| 2  | BADC   | 大端字内反转               | `21 43`        |
| 3  | DCBA   | 小端字内反转               | `43 21`        |

### 7.1 使用场景

| 字节序     | 常见场景                           |
| ---------- | ---------------------------------- |
| 0 (ABCD)   | 标准 Modbus 设备、多数国产设备     |
| 1 (CDAB)   | 某些进口设备（如西门子）           |
| 2 (BADC)   | 某些电力仪表                       |
| 3 (DCBA)   | 某些特殊协议设备                   |

## 9. 数据解析流程

```text
1. 读取配置
   ↓
2. 判断模式
   ├── 有 addrs + template → 单模板模式
   └── 有 templates → 多模板模式
   ↓
3. 遍历模板/从站
   ├── 从站地址 = addrs[i]
   ├── 生成读报文 = addr + func + start + count
   ├── 发送 Modbus 读请求
   └── 接收响应
   ↓
4. 解析参数
   ├── 根据偏移提取数据
   ├── 根据字节序转换
   └── 生成 Key = "从站:地址"
   ↓
5. 写操作（如果写功能码不为空）
   ├── 生成写报文 = addr + writeFunc + start + data
   ├── 发送 Modbus 写请求
   └── 接收写响应
   ↓
6. 下一个从站/模板
```
