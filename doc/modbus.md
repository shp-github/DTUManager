# Modbus 模板配置格式说明文档

**版本**: v1.0  
**更新日期**: 2026-06-28  
**适用范围**: Modbus RTU/TCP 通信配置

---

## 1. 概述

本文档描述了一种模板化 Modbus 配置格式，通过将指令抽象为模板，配合从站地址列表自动生成 Modbus 报文。该格式大幅减少配置文件的体积，解决嵌入式设备 JSON 解析时的内存不足（NoMemory）问题。

---

## 2. 快速开始

### 2.1 单模板（统一从站列表）

```json
{
  "modbus": {
    "enabled": true,
    "protocol": "rtu",
    "inputSource": "serial1",
    "outputSource": [0],
    "interval": 50,
    "addrs": [1, 2, 3],
    "template": [
      [
        "03",
        0,
        18,
        [
          ["", 0, 2, 0],
          ["", 2, 2, 0],
          ["", 4, 2, 0]
        ]
      ]
    ]
  }
}
```

### 2.2 多模板（不同从站使用不同指令）

```json
{
  "modbus": {
    "enabled": true,
    "protocol": "rtu",
    "inputSource": "serial1",
    "outputSource": [0],
    "interval": 50,
    "templates": [
      {
        "addrs": [1, 2, 3],
        "commands": [
          ["03", 0, 18, [["",0,2,0],["",2,2,0],["",4,2,0]]]
        ]
      },
      {
        "addrs": [6, 7, 8],
        "commands": [
          ["03", 100, 6, [["",100,2,0],["",102,2,0],["",104,2,0]]]
        ]
      }
    ]
  }
}
```

## 3. 顶层参数说明

| 字段           | 类型    | 必填 | 说明                      | 示例                      |
| -------------- | ------- | ---- | ------------------------- | ------------------------- |
| `enabled`      | boolean | 是   | 是否启用 Modbus 功能      | `true`                    |
| `protocol`     | string  | 是   | 通信协议类型              | `"rtu"` 或 `"tcp"`        |
| `inputSource`  | string  | 是   | 数据输入源                | `"serial1"`, `"serial2"`  |
| `outputSource` | array   | 是   | 数据输出目标通道          | `[0]`                     |
| `interval`     | number  | 是   | 轮询间隔（毫秒）          | `50`                      |

### 3.1 单模板模式（`addrs` + `template`）

| 字段       | 类型  | 必填 | 说明                  | 示例                |
| ---------- | ----- | ---- | --------------------- | ------------------- |
| `addrs`    | array | 是   | 从站地址列表          | `[1, 2, 3, 4, 5]`   |
| `template` | array | 是   | 指令模板列表          | 见下文              |

### 3.2 多模板模式（`templates`）

| 字段         | 类型  | 必填 | 说明                          |
| ------------ | ----- | ---- | ----------------------------- |
| `templates`  | array | 是   | 模板组列表，每组含独立的从站地址和指令 |

`templates` 中每个元素的结构：

| 字段       | 类型  | 必填 | 说明           |
| ---------- | ----- | ---- | -------------- |
| `addrs`    | array | 是   | 从站地址列表   |
| `commands` | array | 是   | 指令模板列表   |

## 4. 模板格式说明

### 4.1 单条模板结构

```json
[
  "03",                    // 功能码（十六进制字符串）
  0,                       // 起始寄存器地址
  18,                      // 寄存器数量
  [                        // 参数映射列表
    ["", 0, 2, 0],         // [Key, 偏移, 长度, 字节序]
    ["", 2, 2, 0],
    ["", 4, 2, 0]
  ]
]
```

| 位置     | 类型   | 说明                  | 示例                  |
| -------- | ------ | --------------------- | --------------------- |
| `[0]`    | string | 功能码（十六进制）    | `"03"`, `"04"`, `"01"` |
| `[1]`    | number | 起始寄存器地址        | `0`, `18`, `36`       |
| `[2]`    | number | 寄存器数量            | `18`, `6`, `12`       |
| `[3]`    | array  | 参数映射列表          | 见下表                |

### 4.2 参数映射格式

```json
["", 寄存器偏移, 数据长度, 字节序]
```

| 位置     | 类型   | 说明                            | 示例        |
| -------- | ------ | ------------------------------- | ----------- |
| `[0]`    | string | Key 名称（留空自动生成）        | `""`        |
| `[1]`    | number | 寄存器偏移（相对于起始地址）    | `0`, `2`, `4` |
| `[2]`    | number | 数据长度（字节数）              | `1`, `2`, `4` |
| `[3]`    | number | 字节序类型                      | `0`, `1`, `2`, `3` |

---

## 5. 报文自动生成规则

程序根据从站地址和模板自动生成 Modbus 报文：

```text
报文 = 从站地址(2位) + 功能码(2位) + 起始地址(4位) + 寄存器数量(4位)
```

### 5.1 生成示例

| 从站地址 | 功能码 | 起始地址 | 寄存器数量 | 生成报文       |
| -------- | ------ | -------- | ---------- | -------------- |
| 1        | "03"   | 0        | 18         | `010300000012` |
| 1        | "03"   | 18       | 18         | `010300120012` |
| 2        | "03"   | 0        | 18         | `020300000012` |
| 10       | "03"   | 0        | 18         | `0A0300000012` |

### 5.2 Key 自动生成规则

```text
实际寄存器地址 = 起始地址 + 偏移
Key = "从站地址:实际寄存器地址"
```

| 从站 | 起始地址 | 偏移 | 实际地址 | 生成 Key |
| ---- | -------- | ---- | -------- | -------- |
| 1    | 0        | 0    | 0        | `"1:0"`  |
| 1    | 0        | 2    | 2        | `"1:2"`  |
| 2    | 18       | 0    | 18       | `"2:18"` |

---

## 6. 字节序类型说明

| 值 | 名称   | 说明                       | 示例（0x1234） |
| -- | ------ | -------------------------- | -------------- |
| 0  | ABCD   | 大端模式（标准 Modbus）    | `12 34`        |
| 1  | CDAB   | 小端模式                   | `34 12`        |
| 2  | BADC   | 大端字内反转               | `21 43`        |
| 3  | DCBA   | 小端字内反转               | `43 21`        |

### 6.1 使用场景

| 字节序     | 常见场景                           |
| ---------- | ---------------------------------- |
| 0 (ABCD)   | 标准 Modbus 设备、多数国产设备     |
| 1 (CDAB)   | 某些进口设备（如西门子）           |
| 2 (BADC)   | 某些电力仪表                       |
| 3 (DCBA)   | 某些特殊协议设备                   |

## 8. 数据解析流程

```text
1. 读取配置
   ↓
2. 判断模式
   ├── 有 addrs + template → 单模板模式
   └── 有 templates → 多模板模式
   ↓
3. 遍历模板/从站
   ├── 从站地址 = addrs[i]
   ├── 生成报文 = addr + func + start + count
   ├── 发送 Modbus 请求
   └── 接收响应
   ↓
4. 解析参数
   ├── 根据偏移提取数据
   ├── 根据字节序转换
   └── 生成 Key = "从站:地址"
   ↓
5. 输出结果
   ↓
6. 下一个从站/模板
```
